# Code of Conduct

## Our Pledge

We are committed to creating a respectful, welcoming, and harassment-free environment for everyone.

## Expected Behavior

- Be respectful and constructive.
- Welcome different experience levels.
- Give helpful feedback.
- Focus on improving the project.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Discriminatory language.
- Publishing private information without permission.
- Disruptive or bad-faith participation.

## Enforcement

Project maintainers may remove comments, issues, pull requests, or contributions that violate this code of conduct.
