# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-09

### Added

- Browser-based Nova voice assistant.
- Flask backend with command handling.
- AI response integration through environment variable configuration.
- SQLite conversation history.
- Day, month, and year history grouping.
- CSV history export.
- Light and dark themes.
- Responsive sidebar.
- Voice input preview before sending.
- Spoken assistant responses.
- Professional GitHub documentation files.
